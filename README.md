**Emberward — The Last Lantern** is an original arena-survival game that runs offline in a desktop browser from static files — no build step, no libraries, no network requests, no asset files. You are the last lantern-keeper of a valley gone dark. Walk with **WASD / arrow keys**, dash untouchable with **Space**, and gather the ember shards dropped by the Hollow that swarm you in thickening waves. Every level offers a choice of boons — hotter Lantern Bolts, Orbit Wisps, a Dawn Nova, Cinder Seekers, and charms of speed, might, magnetism and heart. Survive four minutes and the Hollow Star itself descends: put it out and dawn breaks; fall first and the light goes out. Every sound is synthesised live with WebAudio.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
